# Test fixtures

`test_read_format_*` fixtures originate unchanged (UUdecoded) from `libarchive/test` in the official libarchive 3.8.10 source distribution. See `../../../Vendor/COPYING` and the corresponding upstream C test files for attribution and expected data. These contain generated test text/data, not manga.

`portrait.png`, `square.png`, `images.zip`, `unsafe.zip` are synthetic generated fixtures. `pixel.webp` is a one-pixel WebP decode probe. Archive tests verify extracted RAR bytes against upstream's generator, not just entry counts. EXIF JPEG fixtures are generated by Image I/O in an isolated temporary directory at test runtime.
